# Manjaws Portfolio

My personal portfolio website, My name is Gbenle Kamolideen Ajibola, also known as Manjaws.

This portfolio presents my work, technical skills, projects, learning journey, and professional interests across DevOps, Cloud Computing, Cybersecurity, Software Engineering, and AI Automation.

The project was originally built with HTML, CSS, and JavaScript, then converted into React using reusable components and React state management.

## About the Project

The portfolio is designed to present my technical profile in a clean, responsive, and structured format.

The React version focuses on:

- Reusable components
- Responsive design
- Interactive navigation
- Project filtering
- Animated statistics
- Contact form validation
- Mobile navigation
- Back-to-top interaction
- Cleaner frontend structure

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
- React Hooks

## Main Features

- Responsive desktop and mobile layout
- Sticky navigation header
- Active navigation state while scrolling
- Mobile menu toggle
- Animated About section counters
- Project category filtering
- Contact form validation
- Individual field error messages
- Email submission through mailto
- Back-to-top button
- Downloadable CV
- External project links
- Favicon support
